# 012 — Frontend

**Fecha:** 2026-10-13 · **Estado:** aceptada

## Decisión
React + **TypeScript** + Vite + Tailwind + Plotly, con `react-router` para tener páginas reales (login, casos, simulación, arquetipos, admin). Los componentes del prototipo (`.jsx`) se migran a `.tsx` durante el sprint 0.

## Alternativas descartadas
- **React + JavaScript:** sin migración, pero sin la detección de errores en tiempo de desarrollo; el equipo prefiere TypeScript, ya que el desarrollo se apoya en IA.
